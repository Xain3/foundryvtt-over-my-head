# Log Files

This folder contains log files generated during the development session. These logs capture debugging information, errors, and other runtime data for troubleshooting and monitoring purposes.

Log files are automatically deleted regularly to prevent accumulation of outdated data.

The content of this folder, except for this README.md file, is ignored by version control systems to prevent cluttering the repository with log data.
